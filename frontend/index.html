정책 평가
학습 기록의 평가 버튼으로 해당 PushT 또는 MuJoCo ALOHA 환경에서 정책을 실행하고 영상을 저장합니다. 같은 입력·Seed·스텝 제한의 결과끼리 비교하세요. 상태 입력 강화학습은 시뮬레이터의 물체 상태를 직접 제공받습니다.

      

        
AGENTS + LEARNING SKILLS
학습 결과를 다음 실험으로 연결합니다.

        
분석 Agent → 설계 Agent → 기준·후보 학습과 평가 → 독립 검토 Agent. 같은 환경과 방법에서 설정 하나를 바꾸고, 새로운 동일 Seed로 두 정책을 비교합니다. PushT와 MuJoCo ALOHA를 지원합니다.

        

          
          
          
          
          
        

        
원본은 분석 근거로 사용합니다. 기준과 후보 모두 작은 모델로 새로 학습하는 파일럿 실험입니다. 연산 장치는 위 학습 설정을 사용합니다. 학습 설정·숫자 지표는 연결된 Hermes 모델 제공자로 전달되며, 영상은 로컬에 저장됩니다. 결과는 자동 채택하지 않습니다.
